## 重新生成

依赖：Node.js + 本机 Microsoft Edge（Chromium 内核，无需安装其他依赖）。

```powershell
node build.js          # 生成 18 张 PNG + 3 份 PDF
node build.js --fit    # 只检查每页内容是否放得下
node preview.js 0      # 预览第 1 个框（下标从 0 开始）
```

> 如果 Edge 不在默认路径，先设置 `$env:EDGE_PATH="C:\...\msedge.exe"`。

## 源码结构

- `mindlib.js` —— A4 单页 SVG 渲染内核（页眉、树状分支、易错面板、结论条、页脚）
- `content.js` —— 16 个框题的主干内容
- `panels.js` —— 每框的“易混易错 / 答题模板”和补充细节
- `build.js` —— 封面、目录、批量渲染（Edge 无头模式截图 + 打印 PDF）
- `pages/` —— 每页 HTML；`print-all.html` / `print-b1.html` / `print-b2.html` —— 打印源

版式约定：“★”为高频考点；粉底“※”为易错提醒；页脚为“框号 · 第几页”。
