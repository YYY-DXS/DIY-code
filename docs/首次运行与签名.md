# 首次运行提示与代码签名

## 一、可直接粘进 README 的段落

```markdown
### 首次运行被 SmartScreen 拦住了？

会。本项目的 exe 没有购买商业代码签名证书，Windows 对"没有信誉的新程序"一律拦截，
这是提示，不是报毒。确认来源后这样通过：

1. 点弹窗里的 **更多信息** → **仍要运行**
2. 或者：右键 exe → **属性** → 勾选 **解除锁定** → 确定
3. 或者 PowerShell：`Unblock-File .\你的程序.exe`

通过前请先核对完整性（可选但推荐）：

```powershell
Get-FileHash .\tech-pulse.zip -Algorithm SHA256
# 与 Release 里的 SHA256SUMS.txt 对照
```

如果你不放心，也可以直接读源码、自己构建——仓库里只有 Markdown 与源码。
```

## 二、为什么会出现（机制）

SmartScreen 不看你"是不是好人"，只看两样：

1. **文件哈希有没有信誉**：这个具体文件被多少人下过、有没有被举报
2. **发布者证书可不可信**：有没有公共 CA 签发的代码签名证书

新编译出来的 exe 两样都没有，所以必然被拦。关键点：

- PyInstaller 每次构建都会生成新的 exe，**哈希变了，信誉从零开始**——"用的人多了自然就好了"对你不成立
- **自签名证书无效**：SmartScreen 只认公共 CA 的代码签名证书，自签只会让"未知发布者"更显眼
- 对已签名的程序，信誉挂在**证书**上而不是文件上，所以固定一张证书、持续发布，信誉才会累积

## 三、方案对比

| 方案 | 成本 | 门槛 | 效果 |
| --- | --- | --- | --- |
| SignPath Foundation | 免费 | OSI 许可的开源项目，需申请审核 | 提供签名 + 与 GitHub Actions 集成，信誉逐步累积 |
| Certum Open Source Code Signing | 约 €100–200/年 | 开源项目 | OV 级，仍需累积信誉 |
| 普通 OV 证书 | $200–400/年 | 企业/个人可申请，必须硬件令牌或云 HSM | 需数周到数月累积信誉 |
| EV 证书 | $300–700/年 | 审核更严，硬件令牌/HSM | **立即**获得 SmartScreen 信任 |
| Azure Trusted Signing | $9.99/月 | 组织需 3 年注册历史；个人需 3 年可验证历史 | 便宜、CI 友好，但资质容易卡住 |
| Microsoft Store / MSIX | 个人账号约 $19 一次性 | 需 MSIX 打包 | 绕过 SmartScreen，但要改打包方式 |

## 四、建议的落地顺序

1. **本周**：README 加"首次运行"段落（上面那段）+ 一张弹窗截图；Release notes 首行标注"未签名，请核对 SHA256"
2. **两周内**：申请 SignPath Foundation（把仓库地址和 `.github/workflows/release.yml` 给它们）
3. **有预算**：上 EV 证书，直接省掉几个月的信誉累积；预算紧就先 Certum 的 OSS 证书
4. **发布习惯**：证书固定不变；能合并的小版本就合并，减少重编译次数

## 五、release.yml 里加签名的位置

签名必须在**打包 zip 之前**，否则 SHA256 对不上：

```yaml
      - name: Build apps            # 现有步骤：先构建出 exe
        ...

      - name: Sign executables
        if: ${{ secrets.SIGNING_CERT != '' }}
        shell: pwsh
        run: |
          # SignPath / Azure Trusted Signing / signtool 三选一
          & signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a `
            (Get-ChildItem -Recurse -Filter *.exe | Select-Object -First 1).FullName

      - name: Package apps          # 再打包、再算哈希
        ...
```
