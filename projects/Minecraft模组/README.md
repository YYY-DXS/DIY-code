# Minecraft 现实主义模组

## 目标

做一个**现实主义风格**的《我的世界》模组：把真实世界的物理规律、生存机制
和环境交互塞进游戏里。技术路线是 Minecraft Forge。

## 设计方向

### 一、真实生存系统

- **体温与气候**：按生物群系动态调整体温 —— 雪原掉温、沙漠脱水；
  靠穿衣物、靠近火源、喝温水维持平衡
- **疾病与健康**：伤口感染、食物中毒；生肉可能引发寄生虫，需要药物或特定植物治疗
- **体力与疲劳**：长时间奔跑或挖掘消耗体力，靠休息或高热量食物恢复

### 二、环境互动增强

- **动态物理**：建筑要符合力学逻辑（悬空方块可能坍塌），木质结构会被雨水腐蚀
- **季节与生态循环**：四季更替影响作物生长周期（冬季停止生长）、动物迁徙
- **自然灾害**：随机洪水、地震、森林火灾，逼玩家建防洪堤或灭火系统

### 三、资源管理真实化

- **工具耐久与维护**：磨损后可以修复，而不是直接消失；需要磨刀石或工作台
- **资源稀缺性**：关键资源不再随处可得，需要规划采集路线
