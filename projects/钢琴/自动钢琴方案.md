# ESP32 便携自动钢琴

## 项目简介

不需要改装钢琴：用可折叠龙门架 + 24 个电磁铁，就能让钢琴自动演奏任意 MIDI 曲目。
支持 SD 卡离线播放，可选语音控制（说歌名自动弹奏），整套装置收进一个铝合金工具箱，
用支持 PD 12V 输出的充电宝供电，「开箱即演」。

> 由来：最初想的是「外骨骼帮我弹琴」，评估后发现行不通（见
> [外骨骼方案](../外骨骼/方案.md)），于是改成直接驱动琴键 —— 效果更好，难度更低。

## 核心设计

| 项目 | 方案 |
| --- | --- |
| 按键布局 | **24 键固定布局**，覆盖 C3–C5 及关键黑键，适配绝大多数流行曲目 |
| 执行器 | JF-0530B 12V 推拉式电磁铁 × 24（行程 10 mm） |
| 驱动 | 6 块 IRF520 四路 MOSFET 模块（共 24 路）+ 2 片 PCA9685 级联出 24 路 PWM |
| 主控 | ESP32-WROOM-32，一块板子管 MIDI 解析、电磁铁时序、SD 读取、语音识别 |
| 电源 | 续流二极管 1N4007 × 24 保护电路；PD 12V 充电宝直驱 |
| 播放 | SD 卡存 MIDI 文件，脱机独立演奏，支持按键/串口切换 |
| 本机操作 | 0.96 寸 OLED（SSD1306）+ 4×4 矩阵键盘，脱机选曲、切歌、配网，不依赖电脑 |
| 语音（选配） | 离线唤醒 + 在线搜索，说歌名自动下载并弹奏 |
| 收纳 | 可折叠龙门架 + 铝合金工具箱，约 1 分钟组装 |

## 预算

物料总计约 **634 元**，逐项相加口径（逐条价格与采购批次见 [材料与采购规划](../材料与采购规划.md)）：

| 部分 | 金额 |
| --- | --- |
| 电磁铁 24 个（8 元/个） | 192 元 |
| MOSFET 模块 6 块（12 元/块） | 72 元 |
| 主控、PCA9685、SD 卡、OLED、键盘、麦克风 | 121 元 |
| 工具箱、铝型材、亚克力、螺丝磁吸等架体 | 198 元 |
| 线材、开关、诱骗线、续流二极管 | 51 元 |

> 早期讨论里写过「约 1400 元」，那是没逐项核算的粗估，和物料表对不上，按 **634 元** 为准。
