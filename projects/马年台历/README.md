# 马年手工台历

## 任务要求

学校布置的手工任务，核心约束：

1. **材料必须是废旧物**（基础原件如小灯泡、电池盒可以买）
2. **共 13 张**：1 张封面 + 12 张月份页，每页独立设计
3. **两个核心元素**：马元素 + 学校特色元素
   - 但不能出现校名、LOGO、姓名
4. **必须手工制作**，不能只是画出来

## 创意方向

- **支架结构**：废纸盒、硬纸板、木片、布料都能用，做成可站立的台历架
- **装订**：环扣、线装、活页夹都可，注意 13 张的厚度和翻页手感
- **每页设计**：月份数字 + 马元素（剪纸、拼贴、立体造型）+ 学校特色（校服色、校树、口号意象）
- **立体化**：用折纸／剪影做层次，比平面绘画更符合"手工"要求

## 后续扩展（电子部分）

讨论到这里之后，又延伸出了电子功能：

- **供电系统**：采用 SX1308 升压模块方案
- **硬件清单**：灯带／小灯泡、电池盒、开关、导线、热熔胶等
