## 初步方案

给模型喷漆，主流选择是**喷笔**和**喷罐**，它们各有侧重：**喷笔**是追求精细效果和专业质感的核心装备；**喷罐**则是无需额外设备的便携入门选择。

我把它们的核心差异整理了一下，方便你对比参考：

| 特性 | 🖌️ 喷笔 + 气泵 | 🖱️ 喷罐 |
| :--- | :--- | :--- |
| **核心特点** | 精细可控，效果专业，一劳永逸。 | 即买即用，无需额外设备，简单方便。 |
| **喷涂效果** | 雾化均匀细腻，色彩过渡自然，适合渐变色、阴影等高级技法，能做出金属质感[reference:0]。 | 颗粒感相对较重，均匀度和控制力较差，容易出现流挂，不适合精细作业[reference:1][reference:2]。 |
| **适用范围** | 所有类型的上色，从大面积底色到精细分色、阴影旧化，无所不能。 | 最适合大面积单色涂装（如骨架、外甲），或喷涂水补土、保护漆[reference:3][reference:4]。 |
| **操作难度** | 需要一定的学习成本和练习来掌握[reference:5]。 | 摇匀即可喷，无操作门槛，但有手部疲劳和“喷一半没气”的问题。 |
| **单次投入成本** | 初期投资高，设备在**几百到上千元**不等[reference:6]。 | 单罐成本低（几十元），但长期使用或大面积喷涂不划算。 |
| **运行成本** | 长期成本极低。耗材仅为油漆和少量稀释剂。 | 长期成本高。油漆利用率低，大量消耗喷罐，不经济[reference:7]。 |

总的来说，如果你计划长期玩模型，追求更好的效果，我会毫不犹豫地推荐你从 **"喷笔 + 气泵"** 的组合起步。而喷罐很适合作为你感受喷涂魅力的第一步，或者作为某些特殊场景（如喷补土）的备用方案。

### 🔧 方案一：专业进阶之选——"喷笔 + 气泵" 组合详解

这个组合是实现模型涂装专业效果的核心，可以让你体验到喷涂的真正乐趣。

#### 1. 喷笔
*   **类型**：首选 **"双动式"**。按下扳机控制出气，后拉控制出漆量，能实现更精细的控制[reference:8]。
*   **口径选择**：
    *   **0.3mm**：**万金油选择**，适用于绝大多数的模型涂装，能兼顾细节与一定的喷涂面积[reference:9][reference:10]。新手入门首选[reference:11]。
    *   **0.2mm 或更小**：用于**极致精细**的局部涂装，如绘制迷彩条纹、高光阴影等[reference:12]。
    *   **0.5mm 或更大**：用于**大面积快速喷涂**，如水补土、底漆和保护漆[reference:13]。

#### 2. 气泵
气泵是喷笔的"心脏"，为喷涂提供稳定气压。
*   **入门之选 (桌面小泵)**：体积小巧，即插即用，适合空间有限的玩家[reference:14]。如**伽利略 Turbox Mini**，不带气罐但性能足以应付日常[reference:15]。
*   **静音性价比之选 (模型专用泵)**：专为模型设计，噪音更低。如**耐唯灰泵二代**，采用可乐瓶稳压，性价比高[reference:16][reference:17]。
*   **经典进阶之选 (带储气罐泵)**：带储气罐可确保气压绝对稳定，有效消除喷涂时的脉冲现象。如**浩盛 AF186**，是许多新手稳定入门的经典选择[reference:18]。
*   **高端静音之选 (电磁泵)**：采用电磁震动技术，静音效果极佳。如**郡士 L5** 系列，适合对噪音极度敏感的用户[reference:19]。

> **一句话建议**：预算充足且空间允许，首选带气罐的泵；空间紧张选桌面小泵；对噪音敏感且有预算，可考虑电磁泵。
