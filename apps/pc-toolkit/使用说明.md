# 电脑管家 PcToolkit 使用说明

一个自己用的 Windows 电脑体检 / 修复 / 整理工具。全部是本地脚本，不联网、不上传任何东西、不弹广告。

---

## 一、先说清楚：它能做什么，不能做什么

**能做的：**

- 只读体检：把电脑的健康状况查一遍（磁盘、垃圾体积、启动项、环境变量、运行库、断掉的快捷方式、报错的设备、最近的错误日志），给一个 0-100 的健康分和一张"该按什么顺序修"的清单。
- 修复运行环境：清理 PATH 里失效/重复/空的目录、补回系统必需路径、修 TEMP/TMP、用微软官方的 DISM + SFC 修复系统文件、重置网络协议栈、重置 Windows 更新组件、重建图标缓存。
- 整理电脑：把下载/桌面/文档里的散落文件按类型（图片、视频、模型与打印、安装包、代码……）归类，可撤销；找重复文件、找占空间的大文件。
- 清理垃圾：临时文件、错误报告、崩溃转储、浏览器缓存、回收站、Windows 更新缓存、WinSxS 组件仓库。

**不能做的（别被"修复所有运行文件"这种说法骗了）：**

- 任何工具都不能"一键修复所有运行文件"。某个游戏报 `缺少 xxx.dll`，如果是**这个软件自带的文件**丢了，只能重装这个软件；本工具能做的是修系统自带组件、补齐通用运行库（VC++ / .NET）、把系统文件和网络组件恢复到官方状态。
- 不修硬件。硬盘有物理坏道、内存条坏了、显卡虚焊，软件层面救不回来（但体检里的 SMART 状态能提前告诉你硬盘危险）。
- 不重装、不激活、不破解任何软件。
- 不能保证 100% 修好——它做的是"把系统里能查的都查出来、能安全修的按官方方式修一遍"。

## 二、怎么运行（图形界面版，推荐）

**双击 `启动.bat`** → 打开一个窗口界面（浅色简洁风格）：上面是标题栏，左边是功能菜单，右边是操作区，底部实时显示运行日志。

窗口长这样：

```
┌──────────────────────────────────────────────────────────────────┐
│ ⬛ 电脑管家 v1.0   体检·修复·整理·清理      [普通权限] [提权重启] │
├───────────┬──────────────────────────────────────────────────────┤
│ 电脑体检  │  电脑体检                                            │
│ 文件整理  │  只读检查，不改动任何东西……                          │
│ 垃圾清理  │  ┌────────────────────────────────────────────────┐  │
│ 系统修复  │  │  78    体检结果：还有 3 个问题要处理…          │  │
│ 空间管理  │  └────────────────────────────────────────────────┘  │
│ 使用说明  │  [ ] 快速模式    [ 开始体检 ]   [ 打开上次报告 ]    │
├───────────┴──────────────────────────────────────────────────────┤
│ 运行状态：就绪  ▓▓▓▓▒▒▒▒   收起日志  中止任务  清空  复制日志    │
│  >> 读取系统概况...                                              │
│  [注意] 未检测到 VC++ 2015-2022 x64 运行库                        │
└──────────────────────────────────────────────────────────────────┘
```

窗口里的几个要点：

- **右上角**显示当前权限（普通 / 管理员）。需要管理员的操作会弹窗问你「要不要用管理员身份重新打开」，点「是」就自动提权重启，不用自己右键。
- **每个会改动系统的操作都会先弹确认框**，写清楚要做什么、有什么后果，确认了才动手。
- 底部日志**实时滚动**，`[问题]` 红色、`[注意]` 橙色、`[OK]` 绿色、`>>` 蓝色，一眼能看出哪句重要。DISM / SFC 这种慢操作的输出也会一条条显示，不会像黑框那样看着像卡死。
- 觉得日志占地方，点「收起日志」就只留一行状态条；想看细节再点「展开日志」。
- 「中止任务」可以尝试停掉正在跑的任务（系统命令可能要等它自己结束）；「复制日志」可以把全部日志复制到剪贴板，方便发给我或别人看。
- 界面配色、字号、按钮都集中在 `ui\MainWindow.xaml`，想换成别的风格（深色、绿色主题）改那一个文件就行。

### 放到桌面上当软件用

两种方式都行：

- 双击 `创建桌面快捷方式.bat`
- 或者打开窗口 → 左边选「使用说明」→ 点「创建桌面快捷方式」

都会在**桌面**和**开始菜单**里创建「电脑管家」快捷方式（带图标，启动时不弹黑框）。以后直接从桌面双击就行。

> 如果提示建不了：少数电脑的桌面文件夹被安全软件保护（比如"受控文件夹访问"），这种情况下直接双击 `启动.bat` 效果完全一样，只是桌面上没有那个图标。

### 如果窗口打不开

- 用记事本打开 `_记录\GUI日志_日期.log`，里面会记录启动失败的原因。
- 手动提权运行：Windows 搜索「PowerShell」→ 右键「以管理员身份运行」→ 输入：

```powershell
cd "你的路径\电脑管家"
powershell -ExecutionPolicy Bypass -File .\PcToolkitGui.ps1
```

> `-ExecutionPolicy Bypass` 只是让这次运行不被"禁止运行脚本"的策略拦住，不会修改系统设置。

## 三、界面功能一览

左边 6 个页面，各自对应一类操作：

| 页面 | 主要按钮 | 说明 |
| --- | --- | --- |

| **修复运行环境** | ①创建还原点 ②环境变量修复 ③系统文件修复 ④运行库 ⑤网络 ⑥更新组件 ⑦图标缓存 ⑧磁盘检查 + 一键修复 | 每一步都有说明和确认框；带①的建议先做（可以回退） |
| **重复文件 / 大文件** | 查找重复文件 / 搬走多余副本 / 查找大文件 | 按内容哈希比对（不是看文件名）；多余副本只**移动**到备份文件夹，不删除 |
| **使用说明** | 打开完整说明 / 打开命令行版 / 打开工具文件夹 | 就是本文，外加两个入口 |

## 四、推荐的使用顺序

**第一次用（大约 15 分钟）：**

1. 打开窗口 → 左边选 **一键体检** → 点「开始体检」（不需要管理员）。跑完看日志里的"处理建议"，按顺序处理。
2. 左边选 **修复运行环境** → 点 **① 创建系统还原点**（会弹窗提权）。这一步很重要，万一后面出问题可以回退。
3. 点 **② 环境变量修复**：PATH 变规矩之后，`python`、`git`、`ffmpeg` 这类命令找不到的问题常常就好了。
4. 左边选 **清理垃圾** → 点「预览可清理体积」，再点「执行清理」。想更彻底，勾选「深度垃圾」和「隐私痕迹」；隐私清理不可恢复，浏览器开着时会自动跳过浏览器部分。
5. 点 **③ 系统文件修复**（DISM + SFC，10-30 分钟）：对"缺 dll""某个设置打不开""更新总失败"效果最好。做完重启。
6. 重启后再体检一次，对比健康分。

**平时维护（每月一次，5 分钟）：** 体检 + 清理垃圾 + 整理下载文件夹。

**整理文件的建议：**

- 第一次别点"执行整理"，先点"预览方案"，确认归类方式是你想要的。
- 不想动最近下载的东西，就把「只整理 N 天以前」那个框填成 3 或 7。
- 移动完不满意，点「撤销上次整理」，文件回到原位。

## 五、命令行用法（想写计划任务或用脚本调用）

```powershell
# 体检并出报告
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode Scan

# 只整理下载文件夹，按类型分，最近 3 天改过的不动（不加 -Apply 就是只看方案）
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode Organize -Targets "$env:USERPROFILE\Downloads" -MinAgeDays 3

# 真的执行整理，不再逐个询问
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode Organize -Apply -Yes

# 撤销上次整理
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode Undo -Apply

# 预览可清理的垃圾体积
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode Clean

# 深度垃圾：先预览，再加 -Apply 真清理（-IncludeAdvanced 含 Prefetch 等）
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode DeepClean
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode DeepClean -Apply -IncludeAdvanced

# 隐私痕迹：只扫描 / 清理（-Secure 会随机覆写，较慢）
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode PrivacyScan
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode PrivacyClean
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode PrivacyClean -Apply -Secure -PrivacyBrowser -PrivacyWindows

# 用 cipher 擦除系统盘空闲空间（需要管理员）
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode WipeFree -Apply -Drive C:

# 找重复文件
powershell -ExecutionPolicy Bypass -File .\PcToolkit.ps1 -Mode Duplicates -MinSizeKB 128
```

- `-Mode` 可选：`Menu`（默认）、`Scan`、`QuickScan`、`Report`、`Organize`、`Duplicates`、`Large`、`Clean`、`DeepClean`、`PrivacyScan`、`PrivacyClean`、`WipeFree`、`Repair`、`Undo`。

- `-Apply` 表示真的动手，不加就只是预览。`-Yes` 表示不再逐个询问（慎用）。
- 也可以双击 `启动-命令行版.bat`，打开的就是老的黑框菜单（和窗口版共用同一套引擎代码）。
- 图形界面版自检（开发者用，会跑一次快速体检并写结果到 `_记录\自检结果.txt`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\PcToolkitGui.ps1 -SelfTest
```

## 六、安全设计（为什么可以放心用）

- **默认只读**：体检、预览模式不动任何文件；所有会改系统的功能都要先看到"将要做什么"再确认。
- **能备份就备份**：修环境变量前，会把 `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment`、`HKCU\Environment` 导出成 `.reg`，PATH 明文也单独存一份到 `_记录\备份\`。隐私清理涉及的 RunMRU、RecentDocs 等注册表键也会先导出。安全擦除和空闲空间擦除不可恢复，执行前会单独确认。
- **可撤销**：整理文件会把每次移动写进 `_记录\整理记录_时间.json`，界面里点「撤销上次整理」或 `-Mode Undo -Apply` 可以放回原位。
- **不删用户文件**：清理只针对临时文件、缓存、错误报告、转储。删不掉的（正在使用中）会跳过并统计，不会硬删。
- **重复文件不直接删**：多余副本会被移动到 `_重复文件备份_时间戳` 文件夹，你自己确认后再删。
- **需要管理员权限的操作会明说**：窗口版会弹窗问你要不要提权重启，命令行版会提示你重新以管理员身份运行，都不会偷偷提权。
- **不会重复开工**：开始任务时会写一个 `_记录\任务运行中.lock`。如果另一个「电脑管家」窗口（或命令行版）正在跑任务，会先提醒你；如果系统里已经有 DISM / SFC / chkdsk 在跑（比如 Windows 自己在更新，或你另一个窗口在修复），修复类操作会警告你并默认不继续——两个修复抢同一个系统映像容易出问题。
- **日志**：所有动作记录在 `_记录\运行日志_日期.log`，出问题可以回查。

## 七、常见问题

**窗口版打不开 / 一闪就没了？**
看 `_记录\GUI日志_日期.log`，里面会写失败原因。最常见的原因是这台电脑禁用了 PowerShell 脚本（用 `启动.bat` 会自动带 `-ExecutionPolicy Bypass` 绕过），或者 `ui\MainWindow.xaml` 被误删。

**点「创建桌面快捷方式」报错 / 桌面没出现图标？**
说明桌面文件夹被保护或权限不足，脚本会告诉你具体是哪个路径失败。不影响使用：直接双击 `启动.bat` 打开窗口就行。

**命令行版中文是乱码？**
那是老版本 Windows 控制台编码的问题，可以改用窗口版（没有这个问题），或者装上 PowerShell 7；`启动.bat` 会自动优先用 PowerShell 7。

**安全软件报警？**
脚本会读写系统目录、调用 `DISM`/`SFC`/`chkdsk`/`netsh`，行为上确实像"系统维修工具"，可能被启发式扫描盯上。觉得不放心就先用记事本打开 `PcToolkit.ps1` 看一遍——所有代码都是明文的。

**DISM 卡在某个百分比不动？**
DISM 会联网从 Windows 更新下载修复文件，网络慢的时候会卡很久，属正常。窗口版可以点「中止任务」，或直接等；命令行版按 Ctrl+C。也可以先修网络再试。

**执行策略报错「禁止运行脚本」？**
用 `启动.bat` 启动（自带 `-ExecutionPolicy Bypass`），或者手动加上这个参数。

**"撤销上次整理"说找不到记录？**
说明这台电脑还没用本工具整理过文件（记录保存在 `_记录\` 目录，删掉就撤销不了了）。

**健康分很低怎么办？**
不用慌。分数只是把"发现问题"按影响加权。按报告里的建议一条条做，通常先做"环境变量修复 + 清理垃圾 + 系统文件修复"就能提上去一大截。

## 八、文件结构

```
电脑管家\
├── 启动.bat                  ★ 双击这个：打开图形界面
├── 创建桌面快捷方式.bat        在桌面/开始菜单建带图标的快捷方式（调用 CreateShortcut.ps1）
├── CreateShortcut.ps1       建快捷方式的脚本（文件名故意用英文，见下面的小提示）
├── 启动-命令行版.bat           老的黑框菜单版（同一套引擎）
├── PcToolkitGui.ps1         图形界面：窗口、按钮、日志显示、任务调度
├── ui\MainWindow.xaml       窗口的界面布局和配色（想改外观改这里）
├── assets\app.ico           图标（窗口和快捷方式都用它）
├── PcToolkit.ps1            引擎入口：命令行参数、菜单、自动化调用
├── modules\
│   ├── Common.ps1        输出、日志、提权、备份、目录体积统计
│   ├── Shortcut.ps1      创建快捷方式（界面和命令行共用）
│   ├── Diagnostics.ps1   体检（只读采集 + 打分）
│   ├── Repairs.ps1       修复（环境变量/系统文件/网络/更新/缓存/运行库）
│   ├── Privacy.ps1       深度垃圾 + 隐私痕迹（浏览器/最近记录/注册表/DNS/安全擦除）
│   ├── Organize.ps1      整理（归类、重复文件、大文件、撤销）
│   └── Report.ps1        生成 HTML / Markdown / 求助清单报告
├── 报告\                 体检报告、整理记录、大文件清单、重复文件清单
└── _记录\                运行日志、GUI 日志、自检结果、整理记录 JSON、备份
```

> **小提示（踩过的坑）**：`.bat` 文件里写中文文件名很容易踩编码坑——cmd 会用系统代码页解析批处理文件，一旦编码对不上，中文路径就会变成一串 `?`，PowerShell 会报 `Illegal characters in path`。所以脚本文件名统一用英文（`CreateShortcut.ps1`），批处理文件本身只放 ASCII 字符。批处理文件**必须**用 CRLF 换行 + 纯 ASCII 保存，这点在改的时候要注意。

关键点：**界面和引擎是分开的**。`PcToolkitGui.ps1` 只负责"问你要做什么"和"显示输出"，真正的逻辑都在 `modules\*.ps1` 里，所以窗口版和命令行版永远行为一致；想加功能，改模块就行，界面会自动用上。

## 九、想改成自己的版本

脚本分成模块，很容易改：

- 想改归类规则 → `modules\Organize.ps1` 里的 `Get-OrganizeCategoryMap`（比如给 `.stl`、`.3mf` 换分类）。
- 想改体检项 → `modules\Diagnostics.ps1`，每个 `Get-XXXReport` 函数负责一项。
- 想改打分权重 → `Invoke-Diagnostics` 最后的打分部分。
- 想加自动清理规则 → `modules\Repairs.ps1` 的 `Clear-TempFiles`。
- 想改界面外观 → `ui\MainWindow.xaml`（颜色、按钮、布局都在里面，改完保存直接运行就能看到）。
- 想在界面上加新按钮 → 在 XAML 里加一个 `x:Name="BtnXXX"` 的按钮，再在 `PcToolkitGui.ps1` 的"事件绑定"区照抄一段 `add_Click`。
- 换图标 → 用同样的文件名替换 `assets\app.ico`（256×256 的 PNG-in-ICO 最好），再重新运行一次 `创建桌面快捷方式.bat`。
