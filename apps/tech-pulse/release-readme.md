# 科技脉冲 1.1

双击 `TechPulse.exe`，或使用桌面上的“科技脉冲”快捷方式。
程序会启动本地日报服务，并在独立的 WebView2 桌面窗口中展示，不打开系统浏览器。

## 已配置

- 桌面快捷方式：科技脉冲
- Windows 登录自动启动：已启用，后台启动，不弹出浏览器
- 默认日报时间：每天 08:00，中国标准时间
- 设置与日报目录：`data/`

推送时间、新闻源、兴趣关键词、Webhook 等均可在页面右上角“设置”中修改。

页面右上角的“回看”会记录你实际打开过的文章和项目，列出最近看过的内容，
并按打开次数展示最常浏览内容。阅读记录保存在 `data/view-history.json`。

生成日报时，程序会摘取排名靠前文章的正文和图片并缓存到 `data/cache/`。
外部网站暂时无法访问时，仍可从本地缓存打开阅读视图。正文、副标题和命中兴趣
使用更大的字号；点击右上角“兴趣词”可以直接修改参与排序的关键词。

## 关闭与卸载

- 双击 `停止科技脉冲.cmd` 可关闭后台服务。
- 双击 `移除开机启动.cmd` 可取消登录自动启动，不影响桌面快捷方式。
- 删除快捷方式不会删除 `data/` 中的设置和日报。

请保留整个 `TechPulse` 文件夹。移动文件夹后，需要重新创建快捷方式。
