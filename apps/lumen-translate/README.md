# Lumen 译 · 桌面翻译器 v0.4

一个深色科技风的 Windows 桌面翻译工具：

- **选中即翻译**：在任意程序里拖选一段或双击一个词，**不用按键**就自动弹出译文
- **截图翻译**：框选屏幕任意区域，OCR 出文字再翻译（`Ctrl+Alt+S`）
- **划词翻译**：也可以按 `Ctrl+Alt+T` 手动翻当前选中内容
- **全局快捷键**：划词、翻译剪贴板、显隐主窗口，在别的程序里也能直接按
- **系统托盘**：关掉窗口不退出，缩在托盘里随时唤起
- **双引擎**：在线免费线路（`有道 → MyMemory → Google` 自动降级）/ AI（任意 OpenAI 兼容接口）

只用 Python 标准库 + tkinter + ctypes 直接调 Win32，**零第三方依赖**，不用 pip install。

## 快速开始

**最简单**：双击桌面的 `Lumen Translate` 快捷方式。没建过的话一条命令补上：

```powershell
powershell -ExecutionPolicy Bypass -File lumen-translate\tools\make_shortcut.ps1 -StartMenu
```

也可以双击 `run.cmd`，或者直接：

```powershell
$py = "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe"
& $py lumen-translate\main.pyw
```

启动后它就待在托盘里：单击托盘图标显示/隐藏窗口，右键出菜单。

> 同一时间只允许跑一个实例。重复启动会弹提示——两个实例会抢同一套全局快捷键，
> 与其静默失效，不如直接说清楚。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+Alt+T` | **划词翻译**：翻译当前程序里选中的文字（全局，别的程序里也管用） |

| `Ctrl+Alt+L` | 显示 / 隐藏主窗口（全局） |

| `Esc` | 停止当前请求；浮窗里按 = 关掉浮窗 |
| `Ctrl+Shift+S` | 交换源/目标语言 |
| `Ctrl+L` | 清空两栏 |
| `Ctrl+Shift+C` | 复制译文 |

（`Ctrl+Alt+T` 在「选中即翻译」开着时基本用不上，留着当手动兜底。）

## 划词翻译是怎么做的

按下 `Ctrl+Alt+T` 之后：

1. 记下当前剪贴板序号
2. 向**当前前台窗口**模拟一次 `Ctrl+C`（走 `SendInput`，不注入 DLL、不装钩子）
3. 轮询剪贴板序号变化，最多等 1.2 秒；有些程序第一次没反应会自动补发一次
4. 读到文本后贴着鼠标弹出浮窗，后台翻译；AI 引擎下是流式吐出

浮窗上：`Esc` 或点右上角 `×` 关闭，鼠标点到别处也会自动关（可在设置里关掉这个行为），
顶部拖拽可以挪位置，底部 `主窗口` 会把原文和译文一起倒回主界面继续编辑。

两个相关开关：

- **复制即翻译**：任何程序里一复制就弹浮窗。默认**关闭**，对多数人是打扰。
- **浮窗智能选方向**：默认开。选中中文译成英文，选中其它语言译成你设的目标语言。

## 选中即翻译（不用按键）

默认开启。在任意程序里**按住左键拖选一段**，或者**双击选词**，松手后浮窗就自己出来了。

实现方式：装一个 `WH_MOUSE_LL` 低层鼠标钩子，判断这次操作是"拖选"还是"双击",
满足条件才去模拟一次 `Ctrl+C` 取词。几个细节是为了不打扰你：

| 情况 | 行为 |
| --- | --- |
| 普通点击（没拖动） | 不触发 |
| 位移小于 6 像素 | 不触发（防手抖） |
| 在 Lumen 自己的窗口里选 | 不触发（否则右键菜单、复制按钮会自己弹窗） |
| 在终端窗口里选 | 不触发（默认，避免误发 Ctrl+C 打断正在跑的命令） |
| 同一个词反复选 | 4 秒内不重复弹 |
| 选中的是超长文本（>3000 字） | 不触发（小工具不需要翻整篇文档） |
| 取完词之后 | 把剪贴板**恢复原样**，不会把你原来复制的东西冲掉 |

自动弹出的浮窗**不抢键盘焦点**——你选完词可以继续在原程序里打字，不会被打断；
点到别的地方它自己就收了。手动按 `Ctrl+Alt+T` 触发的浮窗才抢焦点（这样才能按 `Esc` 关）。

这些都能在「设置 → 划词与托盘」里单独开关。想临时关掉：托盘右键菜单里点一下「选中即翻译」。

> 钩子只在"选中即翻译"开着的时候才装，关掉就卸载，平时不占任何东西。
> 它只读鼠标事件，不注入 DLL、不修改别的程序内存。

## 截图翻译

按 `Ctrl+Alt+S`（或点顶栏「截图」、托盘菜单「截图翻译」）：

1. 主窗口和浮窗先自己藏起来（不然会把自己拍进去）
2. 整屏压暗、十字光标，拖一块区域出来；`Esc` 或右键取消
3. OCR 识别 → 翻译 → 浮窗显示「识别到的原文 + 译文」

识别有两条路，在「设置 → 划词与托盘」里切：

| 方式 | 用什么 | 特点 |
| --- | --- | --- |
| 本地 OCR（默认） | Windows 自带的 `Windows.Media.Ocr` | 免安装、免联网、不花钱，中文很准 |
| AI 视觉 | 你配的 OpenAI 兼容模型（要支持图片） | 识别更准，尤其英文小字；一次调用同时完成识别和翻译 |

实现上几个值得记的点：

- **免安装**：直接调系统自带的 OCR 引擎，不需要 Tesseract、不需要下载语言包。
- **常驻进程**：PowerShell 冷启动要 3 秒以上，所以应用启动时就把 OCR 助手预热好了，
  之后每张图只要 20~300 毫秒。
- **次像素预处理**：屏幕上的小字是 ClearType 次像素渲染的（笔画落在 1/3 像素上、带彩色
  边缘），系统 OCR 对它的英文识别率很差。抓图后会按 R/G/B 的次像素顺序对齐合成灰度再
  放大 2 倍，英文识别率有肉眼可见的提升。
- **中英混排分块**：截图里常常中英混着，整段丢给翻译引擎会被判成"已经是中文"然后原样
  返回。所以按行判断语言，已经是要翻的目标语言的行原样保留，只翻需要翻的部分。

> 实测（这台机器只装了中文 OCR 语言包）：中文识别几乎满分；英文小字会掉字、插空格，
> 意思能看懂但不够干净。英文内容多的话建议打开 AI 视觉那条路。

## 两种引擎

### 在线翻译（默认，无需配置）

按顺序尝试三条公开线路，任何一条限流 / 不通就自动**冷却并跳过**，不再每次白等超时：

| 顺序 | 线路 | 特点 | 冷却 |
| --- | --- | --- | --- |
| 1 | 有道公开接口 | 国内直连，约 0.2–0.5 秒 | 限流 60 秒 |
| 2 | MyMemory | 稳定，约 1 秒，单请求 500 字节（自动分块并发） | 限流 120 秒 |
| 3 | translate.googleapis.com | 国外 / 有代理时最快，国内通常被墙 | 不可达 15 分钟 |

实测（这台机器）：Google 三个域名全部超时，有道 250 ms，MyMemory 1.0 s。正在冷却的线路会显示在状态栏。

**占位符保护**：送出去之前会把 `{name}`、`%s`、`%1$s`、`$(var)`、`<b>`、`&amp;`、
`@string/xxx`、反引号包起来的代码、围栏代码块、URL、邮箱挖成 `{{0}}` 标记，翻完原样还原。
这一步是必需的——有道会把 `{file}` 翻成 `{文件}`。标记被翻译器吃掉时还有第二层兜底：
按占位符切段翻译再拼回，保证占位符一个不少。

### AI 翻译（需要你自己的 API Key）

点顶栏的 `AI`，如果还没配 Key，会直接跳到「AI 引擎」页：

1. 选服务商预设（DeepSeek / OpenAI / 通义 / 智谱 / Moonshot / 本地 Ollama），地址和模型自动填好
2. 粘贴 API Key
3. 点「测试连接」——它会真的发一句 `Hello, world.` 验证，成功会显示返回的译文
4. 保存，回到主界面就是 AI 引擎在翻译

- 走 OpenAI 兼容的 `/chat/completions`，支持**流式输出**（边翻边显示）
- 6 种风格：通用 / 直译 / 口语 / 学术 / 技术文档 / 润色
- 可以追加自定义系统提示（比如“术语表：cache=缓存，token=令牌”）
- Key 只写在本机 `data/config.json`，也可以改用环境变量
  `LUMEN_API_KEY` / `OPENAI_API_KEY` / `DEEPSEEK_API_KEY` / `HANHUA_API_KEY`
- 设置里会显示 Key 的当前来源（配置文件还是哪个环境变量）

底部的 **AI 润色** 不走在线引擎，直接把当前译文交给 AI 引擎重写一遍。

## 其它功能

- **自动翻译**：输入停顿 0.9 秒后自动翻译（300 条内存缓存，重复内容 0 ms 返回）
- **窗口置顶**：翻译时对照别的窗口用
- **历史**：`data/history.jsonl`，上限 500 条，点任意一条回填两栏
- **暗色原生标题栏**：走 DWM，不是自绘假标题栏，任务栏、贴边、最小化都正常
- 右键文本框有粘贴 / 复制 / 全选菜单，译文框可以直接手改

## 已知边界

- 在线线路是**非官方公开接口**，随时可能变更或加严限流。量大、要求稳定就用 AI 引擎。
- Google 线路需要代理，国内直连必然超时；引擎已把它排在最后并长冷却，不会拖慢日常使用。
- 有道单次约 1000 字，MyMemory 单次 500 字节，超长文本自动分块，耗时随之上升。
- 划词依赖模拟 `Ctrl+C`：少数程序（自绘控件、部分游戏、以管理员身份运行的窗口）不响应，
  这类情况先用 `Ctrl+Alt+C` 走剪贴板。
- 截图翻译的本地 OCR 用的是系统语言包。这台机器只有 `zh-Hans-CN`，所以英文小字识别一般；
  想更准就在设置里打开「截图翻译交给 AI 视觉模型」。
- 截图时主窗口会先藏起来；如果你的目标内容正好在 Lumen 窗口后面，记得先把它挪开。
- 终端窗口默认跳过自动划词。真要在终端里用，去设置里打开那一项，但要接受"选区不完整时
  Ctrl+C 可能被当成中断信号"的风险。
- 写自动化脚本时注意：`SetCursorPos` **不会**产生低层鼠标钩子事件，模拟拖选必须用
  `SendInput`（库里的 `win32.move_mouse_absolute`）。
- 全局快捷键被别的软件占用时会显示「已被别的程序占用」，在设置里换一个即可。
- 托盘图标、全局热键需要真实桌面会话；没有 explorer 的环境（纯 SSH / 沙箱）会降级提示不可用。
- 打包成单文件 exe 需要额外装 PyInstaller（`pip install pyinstaller` 然后
  `pyinstaller -w -F -i assets/lumen.ico main.pyw`），当前是源码直跑形态。
